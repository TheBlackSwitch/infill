Infill is a live-in text editor designed for easy integration. It's built on the markdown parser [YAMP](https://github.com/TheBlackSwitch/yamp). Take a look at YAMP if you want to see all infill's available syntax.

Take a look at the [documentation](https://github.com/TheBlackSwitch/infill/wiki) for developer info.

# Features

- Insert **syntax** using user friendly buttons
- Shortcuts for almost all available syntax
- Custom implemented selections for a perfected user interface. Select text inside your html and edit the underlying markdown.
- Easily apply syntax across a selection. Syntax will be applied using an XOR mask
- A dedicated zoom slider for your users' confort
- Disable markdown parsing using the built-in toggle
- Easy implementation and configurability. Each syntax feature and button can be enabled / disabled however you like
- Import / export your files with ease using the built-in buttons
- Full mobile support
- Fully implemented code block highlighting using [prismjs](https://prismjs.com/)

## Themes

Ontop of the default theme, there are 5 other themes available. You can select these themes by importing their corresponding css file. The css is built in such a way that you're able to easily define custom themes.
